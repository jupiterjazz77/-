## 2. 他担当の主張で疑わしい点・矛盾する点

1. **従業員数**: 現場が94名(2026/4、会社概要サイト)を引用し、依頼文は約60名。ライセンス費、50人超の義務(衛生委員会等)、設計の前提が変わる。パート・派遣を含む総数かを要確認。
2. **クラウド例外の前提(法務)**: 個人データを「取り扱わない」契約とアクセス制御があれば提供に当たらないとの整理。商用プランでも運営者側に標準30日の保持があり、安全性検査の対象になる(Anthropic公式文書で確認済み)。生成AIでこの例外が成立するかは疑わしい。名簿を赤とする根拠の一つ。法務で要確認。
3. **統計の母集団(経営・設計)**: 「整備済み企業でも46.9%が公式外AI利用」は、上場または300名以上が対象(懐疑が指摘済み)。60名に直接当てはまらず、因果も言えない。規程本文や根拠欄に使わない。
4. **助成金・補助金**: 人事の助成金要件・金額は二次情報のみで、全員向け汎用教育は対象外になりやすいと人事自身も述べている。教育予算は助成金前提にしない。経営の第6次締切2026/10/30は要確認。私見として、IT導入系補助金はSECURITY ACTION宣言(IPA、無料の自己宣言)が申請要件だった。今期も同様かは要確認。
5. **Copilot Chatの前提(現場)**: 追加料金なしでEDPが付くとの記述。適用はEntraでのサインイン状態に依存すると理解(私見、要確認)。導入前に共有フォルダの権限棚卸しが要る(版下置き場が全員公開だと検索対象になる)。
6. **懐疑の名指し**: 全件の利用台帳・プロンプト保存やDLP/CASBは、私も第1ラウンドで不要と書いた。私の台帳はツール単位の10行程度の表で、プロンプトは保存しない。
7. **個情委の注意喚起の日付**: 懐疑は2023/8と記すが、注意喚起は2023/6/2、パンフレットが2023/8/21(設計が正しい)。
8. **設計の第8条案**: 「個人アカウント・私用端末も同様」は、私物スマホから承認ツールを使うことまで禁じる読みになり、現場に合わない。私案は、私物端末では**緑のみ**、黄/赤は不可。
9. **現場の「原価・単価・取引条件=赤」**: 原価・仕入先条件までは受け入れる。顧客名+単価の見積文面は黄(承認ツール可)とし、見積業務を止めない。

## 3. 譲歩点(撤退ライン)と譲れない点(レッドライン)

**撤退ライン(ここまでは下がる)**
1. 区分は3色に統一し、A〜DとTier二層は運用基準に落とす。
2. 本則はMVP(2枚+別表1・2+1枚もの)まで縮小してよい。
3. 事前承認でなく「届出+5営業日回答」でよい(懐疑案)。ただし、無回答=承認とはしない。
4. ログの四半期レビュー、ベンダー評価10項目(→5項目)、BYOD細則、AI詐欺備えの条文は、本則から外して運用基準・FAQへ。
5. 自己申告は「免責」と書かず「情状」とする。

**レッドライン(これを欠くなら反対)**
1. 個人・無料・消費者版および私物端末への、黄/赤の業務情報の入力禁止。会社が法人ツールを先に用意することとセットにする。
2. 赤は承認ツールでも入力禁止。例外は経営者承認+取引先の書面許諾の両方が揃う場合のみ。
3. 自動実行・外部連携系は、事前承認なしに業務端末で使わない(一文で足りる)。
4. 24時間以内の報告、報告者への不利益取扱い禁止、証跡保全。
5. 「承認済み」の最低要件(会社ID+MFA、学習に使われないことの契約・設定での確認、管理者が停止できること)。満たさないものを承認しない。

## 4. 合意案の骨子(最終規程)

1. 目的: 使うことを前提に、止められない事故(漏えい・権利侵害・誤情報の外部流出)だけを防ぐ。
2. 適用: 役員・正社員・パート・派遣・委託先。私物端末・個人アカウントを含む。AIの定義は挙動で書く(入力が社外サービスに送られる機能。内蔵AI機能・拡張・議事録・画像変換を含む)。
3. 承認済みサービス(別表1)のみで業務を行う。個人・無料・消費者版への業務情報の入力は禁止。
4. 入力できる情報は緑/黄/赤(別表2)。赤は入力禁止。黄は承認サービスのみ。私物端末は緑のみ。
5. 赤の5類型を本則に列挙する: 個人データ・名簿、未発表デザイン、NDA/ライセンサー提供データ、原価・仕入先条件、認証情報。
6. 外部に出す成果物は、人が一次情報で確認する。ライセンス品・新規マークは類似確認と上長承認(法務案)。
7. 自動実行・外部連携を伴う機能と、顧客向けAI機能は、事前承認制(後者は社長承認)。
8. 新規ツール・新用途は5分の届出、5営業日以内に回答する。無回答を承認とはしない。
9. 事故・疑いは直ちに(24時間以内)窓口へ報告する。報告者に不利益を与えない。自分で履歴を消さない。
10. 責任者(社長)・管理責任者・代理・窓口を置く。派遣・委託は契約条項と入場時説明で担保する。
11. 違反は就業規則の懲戒対象となり得る(接続条項)。誠実な自己申告は情状として考慮する。
12. 教育は入社時と年1回。受講完了を新規アカウント付与の条件とする。見直しは半期。
